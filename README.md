# Sistema de Inventario y Ventas

Sistema web para gestión de inventario y ventas con catálogo público para clientes.

## Tecnologías
- **Backend:** Node.js, Express, MongoDB, JWT
- **Frontend:** React, Vite, Tailwind CSS

## Módulos
- Autenticación de administrador
- Gestión de productos
- Control de inventario
- Gestión de ventas
- Catálogo público con carrito y pedido por WhatsApp
- Dashboard y reportes

## Instalación

### Backend
```bash
cd backend
npm install
npm run dev
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```
